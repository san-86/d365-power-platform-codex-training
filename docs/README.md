# Training guide website

`docs/index.html` is a dependency-free, static participant guide for the Codex onboarding session.

## Local preview

Open `docs/index.html` in a browser, or serve the repository with any static web server.

## GitHub Pages

After the repository has been pushed, enable GitHub Pages in repository settings and choose:

- **Source:** Deploy from a branch
- **Branch:** `main`
- **Folder:** `/docs`

The guide will then be available at the repository's GitHub Pages URL.

The page is intentionally self-contained: it has no external scripts, fonts, analytics or customer data.
