# Feature instructions: onboarding guide

## Scope

This feature produces a short internal onboarding guide for consultants supporting the fictional Service Hub solution.

## Required reading

Before planning or writing, read:

- `Spec.md`
- `Acceptance-criteria.md`
- `Workflow.md`
- `../../Architecture.md`
- `../../Decisions.md`
- `../../source-material/Service-catalog.md`
- `../../source-material/Coordinator-quick-notes.md`
- `../../policies/Safe-use-policy.md`

## Feature rules

- Use clear, non-technical language where possible.
- Refer to the fictional solution as **Service Hub**.
- Do not introduce deployment instructions, configuration changes or security-role advice.
- Do not invent a named support team, email address, response time or escalation route.
- Create or edit only `../../output/Onboarding-guide.md`.
- Keep the first deliverable deliberately small: create Section 1 only unless the human explicitly expands the scope.
