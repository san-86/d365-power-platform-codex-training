# Service catalogue extract

This is the authoritative category list for the training scenario.

| Category | Use when | Do not use when |
| --- | --- | --- |
| Access | A user cannot access an approved service or needs a role reviewed. | The requester is reporting a technical defect. |
| Incident | An existing service is not working as expected. | The requester is asking for a new capability. |
| Service request | A user needs a standard, pre-defined service. | The request is a defect or outage. |
| Change | A change to an existing service is requested. | The request is already covered by a standard service request. |

## Priority guidance

- **Low:** Limited impact; a workaround is available.
- **Normal:** Routine business impact; no broad service interruption.
- **High:** Material impact to multiple users or an essential business process.

This extract does not define response-time targets.
