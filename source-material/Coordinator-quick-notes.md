# Coordinator quick notes

## Creating a Service Request

1. Open **Service Hub** and select **New Service Request**.
2. Enter a meaningful title that describes the observed need or problem.
3. Enter the requester's e-mail address.
4. Select the appropriate service category.
5. Set the priority using the category and impact guidance.
6. Add an asset reference when it is known; otherwise save the request without one.
7. Assign the request to the appropriate service team.
8. Confirm that the request is in **New** status when registration is complete.

## Important distinctions

- Saving a request does not mean work has started.
- A coordinator should not mark a request **In progress** until a service team has been assigned.
- The automatic confirmation is a creation-time message. It is not a progress update.
- A Teams conversation does not change the request record automatically.
